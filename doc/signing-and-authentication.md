# Signing and authentication

Diffinch invokes system Git, so existing hooks, credential helpers, SSH agents, and signing programs apply. Remote authentication needs a configured credential helper or SSH agent for unattended Git commands.

For HTTPS remotes, click the key beside a remote in the branch sidebar, or **Repository → Remotes → Credentials**. Enter your username and personal access token or password, then **Save credentials** and retry fetch, pull, or push. The username is remembered in local Git configuration for that URL. Separate fetch and push URLs can be selected independently. The remote remains available in the sidebar before its first successful fetch.

To see the saved account for an HTTPS destination with a configured helper, choose **Check saved account**. Diffinch asks Git which credential it would use and displays only the returned username. It does not expose the password or token in the interface, prefill the password field, or save the lookup result. This is an explicit lookup, so opening the dialog does not access the credential store. Git and Git Credential Manager sign-in prompts are disabled for the lookup, although a helper or the operating system may request permission to unlock its store. Lookups stop after 15 seconds. If nothing is returned, the store may be empty, locked, or require sign-in; this is not proof that no credential exists. The username is the helper's identifier, not a verified hosting-service identity or a test of repository access. SSH accounts are determined by SSH keys and are not looked up through credential helpers.

Use **Credential helper → Apply helper** in the same dialog to choose an installed helper for the selected destination. Diffinch detects macOS Keychain, Git Credential Manager (including its older Core command), libsecret, Windows wincred, and Git's temporary memory cache when Git can find them. The choice is saved only for this URL in this repository; global settings and other destinations are preserved. **Use inherited Git settings** removes this URL's local helper override. Existing custom configurations are kept until you explicitly choose a replacement. Switching helpers does not transfer or delete saved credentials; enter them again if the selected helper needs them. Install missing helpers separately, then reopen the dialog.

If fetch, pull, or push cannot read a username or password, or the server rejects authentication, Diffinch opens **Credentials**. Choose the remote and destination used by the failed operation, save credentials, then retry. GitHub requires a personal access token with repository access rather than your account password. Diffinch keeps terminal prompts disabled because a desktop operation has no terminal for answering them.

Credentials are sent to your configured [Git credential helper](https://git-scm.com/docs/gitcredentials); its settings determine storage and expiration. On macOS, saving enables the Keychain helper for this repository URL if no helper is configured. Other platforms need a configured helper, such as Git Credential Manager or libsecret. Diffinch does not put tokens in app settings, command arguments, or repository configuration. Saving does not verify access to the server. Use an HTTPS URL without embedded credentials, query parameters, or fragments. SSH remotes continue to use your SSH agent and `~/.ssh/config`.

**Forget credentials** asks the helper to remove credentials for the entered username after confirmation. Git normally shares credentials across repositories on the same HTTPS host, so saving or removing them can affect those repositories too; `credential.useHttpPath` controls path matching.

In **Repository Settings**, choose OpenPGP, SSH, or X.509 and enter the key ID or path for that format. For SSH, use the path to a public key whose private key is available to the agent, or the path to a private key your signer can read. For OpenPGP or X.509, configure the signing program and its graphical pinentry separately if the key requires a passphrase. Repository Settings writes changed defaults to the local Git configuration.
